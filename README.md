# Smart Career Tracker

A Java console application that helps users analyze their skills and identify career skill gaps.

## Features

- Add user details
- Set career goals
- Add skills
- Skill gap analysis
- Career progress report

## Technologies Used

- Java
- OOP
- Collections Framework

## How to Run

Compile:

javac Main.java

Run:

java Main
